本页介绍的是玩家运行模组所需的 BepInEx 配置。如果你想制作模组，请参阅搭建 Among Us 模组开发环境。
:::

Among Us 是一款 **Unity IL2CPP 游戏**，因此使用 BepInEx 作为游戏的模组加载器。

:::tip
像 [Starlight PC](https://github.com/All-Of-Us-Mods/Starlight-PC) 和 [Bean Manager](https://github.com/rewalo/BeanModManager) 这样的模组管理器可以自动完成 BepInEx 的配置。
:::

# 手动安装步骤

### 第 1 步：下载 BepInEx
* 下载与你的游戏平台相匹配的 BepInEx 压缩包：

| 游戏平台 | 下载链接 |
| :--- | :--- |
| **Steam** | [`BepInEx-Unity.IL2CPP-win-x64-6.0.0-be.752+dd0655f.zip`](https://builds.bepinex.dev/projects/bepinex_be/752/BepInEx-Unity.IL2CPP-win-x64-6.0.0-be.752%2Bdd0655f.zip) |
| **Microsoft Store** | [`BepInEx-Unity.IL2CPP-win-x64-6.0.0-be.752+dd0655f.zip`](https://builds.bepinex.dev/projects/bepinex_be/752/BepInEx-Unity.IL2CPP-win-x64-6.0.0-be.752%2Bdd0655f.zip) |
| **Epic Games** | [`BepInEx-Unity.IL2CPP-win-x64-6.0.0-be.752+dd0655f.zip`](https://builds.bepinex.dev/projects/bepinex_be/752/BepInEx-Unity.IL2CPP-win-x64-6.0.0-be.752%2Bdd0655f.zip) |
| **Itch.io** | [`BepInEx-Unity.IL2CPP-win-x86-6.0.0-be.752+dd0655f.zip`](https://builds.bepinex.dev/projects/bepinex_be/752/BepInEx-Unity.IL2CPP-win-x86-6.0.0-be.752%2Bdd0655f.zip) |

### 第 2 步：准备模组版游戏文件夹
* 找到你的游戏安装目录，把里面的内容复制到一个新文件夹中。这样可以把「已装模组」和「原版」的游戏安装区分开。

### 第 3 步：解压 BepInEx
* 把 BepInEx 压缩包解压到你新建的文件夹里。

### 第 4 步：首次启动
* 通过运行可执行文件（Among Us.exe）启动游戏。首次启动可能需要一些时间，因为它要下载所需的文件。

### 第 5 步：确认插件文件夹
* 首次启动后，会自动创建 `BepInEx\plugins` 目录。你的模组需要放进这里。

### 第 6 步：安装模组！
* 从网上下载模组（最常见的渠道是 GitHub）。模组以 `DLL` 文件的形式分享，把 DLL 放进 `BepInEx\plugins` 文件夹即可。
