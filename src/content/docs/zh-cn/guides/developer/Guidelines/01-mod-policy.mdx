Innersloth 不算太抵制《Among Us》的玩家自制模组，[模组政策](https://www.innersloth.com/among-us-mod-policy/) 的制定是为了给模组开发者提供一套需要遵循的规则。

这些政策可分为 **3 类**：

### 要求：
1. 必须始终在屏幕上显示 Mod 标识。如果你的模组使用 Reactor，这已经为你处理好了；否则，你必须对 `MainMenuManager.Start` 打补丁，并调用 `ModManager.Instance.ShowModStamp();`
2. 必须在你的模组网站/GitHub 仓库上显示以下免责声明：
``` This mod is not affiliated with Among Us or Innersloth LLC, and the content contained therein is not endorsed or otherwise sponsored by Innersloth LLC. Portions of the materials contained herein are property of Innersloth LLC. © Innersloth LLC.```
   (最好是英文,中文的话可能不太行...不过应该没有模组因为这个被封锁过!)
3. 任何会改变官方服务器上游玩流程的模组（通过添加职业或修改交互逻辑）都必须在创建大厅时中注册；客户端侧模组不受此要求限制。更多信息见[此处](https://github.com/Innersloth-LLC/AmongUsModdingInformation)。
4. 如果你的模组是仅房主模组，你必须使用 Modded（+25）协议，以确保未安装模组的客户端无法通过搜索游戏找到你的游戏。更多信息见下文。

### 不鼓励：
1. 任何形式的模组付费/售卖行为都是不鼓励的，而非禁止。Innersloth 已明确表示希望模组开发者获得报酬，但更希望模组免费。

### 禁止：
1. 制作给其他玩家带来不公平优势的作弊模组。
2. 分发伪装成模组的恶意软件。
3. 以任何形式制作 Among Us 的克隆。
4. 将 Among Us 知识产权整合进其他游戏。
5. 不要以不当、诽谤的方式使用 Among Us 知识产权。
6. 不要随模组分发游戏文件。
7. 不要声称或暗示你的模组获得 Innersloth 认可。

## 模组分类：

Innersloth 将模组归为 **3 类**：

### 全客户端模组：

所有人都必须安装才能游玩的模组。

### 仅房主端 (H系) 模组：

这些模组仅在房主客户端上需要，意味着未安装模组的客户端无需安装该模组即可加入并游玩。  
这类模组通常比所有客户端模组受限得多。

这些模组通常可在官方服务器运行，但必须使用 Modded（+25）协议才能正常工作。

:::note
如果你使用 Reactor，可以在插件类中使用 `[ReactorModFlags(ModFlags.DisableServerAuthority)]` 特性将模组注册为仅房主端模组。

如果你不使用 Reactor，可以打以下补丁将模组注册为仅房主端模组：
```csharp
[HarmonyPatch(typeof(Constants), nameof(Constants.GetBroadcastVersion))]
internal static class ModdedProtocolPatch
{
    public static void Postfix(ref int __result)
    {
        if (AmongUsClient.Instance.NetworkMode == NetworkModes.OnlineGame)
        {
            var revision = __result % 50;
            if (revision < 25)
            {
                __result += 25;
            }
        }
    }
}
```
:::

### 仅客户端模组：

这些模组在你的本地客户端上进行更改，你可以自由使用，而无需其他人安装它们。

:::note
如果你使用 Reactor，可以在插件类中使用 `[ReactorModFlags]` 注册模组。
- 全客户端：使用 `ModFlags.RequireOnAllClients`。
- 仅房主端：使用 `ModFlags.DisableServerAuthority`。
- 仅客户端：使用 `ModFlags.None`。
:::
