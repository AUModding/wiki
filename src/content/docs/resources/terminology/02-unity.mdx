### Unity

The game engine that Among Us uses. Unity games are written in C#, and the games themselves can be
compiled to two different scripting backends: Mono and IL2CPP. Among Us uses IL2CPP.
Because of the way IL2CPP works, there is a Mono version of Among Us, but we will get back to this later.

### Mono

An older, open-source implementation of the .NET Runtime. Mono games compile their code to IL in regular DLLs,
which are JIT compiled as the game runs. Because IL is easily converted back into C# code,
Mono games are easy to reverse engineer, and therefore easy to mod. In the case of Among Us, a Mono
DLL is provided by InnerSloth to make modding easier.

### IL2CPP

Developed by Unity to convert IL code into C++, then compile to assembly code.
This comes with many benefits, like various optimizations and speedups that can only happen when you
compile the app [Ahead-Of-Time](../01-csharp/#ahead-of-time-aot). However, IL2CPP makes reverse engineering much more difficult because
assembly code cannot be turned back into C++ as easily as IL to C#. It also makes developing mods more difficult
because modding IL2CPP games from C# requires an interop layer (see [Il2CppInterop](https://github.com/BepInEx/Il2CppInterop)).

### Interop

Since IL2CPP converts the game into C++, but your mod is
written in C#, they speak different languages. "Interop" is the translator
sitting between them. Crossing this translation boundary takes computational
effort, so you want to cross it as little as possible to avoid lag.
