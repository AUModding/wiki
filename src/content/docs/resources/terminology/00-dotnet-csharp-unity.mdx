There is a lot of terminology and information you will be expected to know. Please try your best
to understand the following:

## C# Compilation

- **.NET Runtime**: The "program" that runs your C# code. When you run a C# program, your
computer is not directly running it. Your computer runs a program called the .NET runtime,
which will actually run your C# code. In Among Us modding, we use the .NET runtime to run
our mods on top of the game.

- **IL (Intermediate Language)**: Similar to assembly language, but for the .NET runtime
instead of your computer. C# programs are compiled into IL, then .NET compiles that IL into assembly
for your specific machine at runtime. This is called Just-In-Time, or JIT, compilation.

- **Just-In-Time (JIT)**: JIT compilation makes it easier to develop cross-platform apps, 
but comes at the cost of slower app startup and more memory usage. In the context of
Among Us mods, the .NET Runtime reads the IL code from your mod and converts it into 
assembly code for your computer when the code is about to run.

- **Ahead-Of-Time (AOT)**: AOT compilation turns source code directly into assembly code
without any runtime compilation. The main benefits of AOT are faster startup times, 
lower memory usage, and lower CPU usage. AOT is also required for some platforms,
like iOS, which do not allow JIT programs to run. In the context of Among Us modding,
the Among Us game itself uses AOT because it is built with IL2CPP.

## Unity Backends

- **Unity**: The game engine that Among Us uses. Unity games are usually written in C#, and the
games themselves can be compiled to two different scripting backends: Mono and IL2CPP. Among Us
uses IL2CPP. Because of the way IL2CPP works, there is a Mono version of Among Us, but we will get back
to this later.

- **Mono**: An older, open-source implementation of the .NET Runtime. Mono games are easy
to reverse engineer because IL code is easy to convert back into C# code. Mono games are also easy
to mod because you can write a standard C# program targeting the Mono runtime (usually netstandard)
and add it to the game files.

- **IL2CPP**: Developed by Unity to convert IL code into C++, then compile to assembly code.
This comes with many benefits, like various optimizations and speedups that can only happen when you
compile the app "Ahead-Of-Time". However, IL2CPP makes reverse engineering much more difficult because
assembly code cannot be turned back into C++ as easily as IL -> C#. It also makes modding more difficult
because modding IL2CPP games from C# programs requires an interop layer (Il2CppInterop).
