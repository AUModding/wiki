:::note
This page covers setting up BepInEx for users to run mods. For making mods, see Setting up your developer environment for modding Among Us.
:::

Among Us is a **Unity IL2CPP Game**. As so, BepInEx is used as a mod loader for the game.

:::tip
Mod managers like [Starlight PC](https://github.com/All-Of-Us-Mods/Starlight-PC) and [Bean Mod Manager](https://github.com/rewalo/BeanModManager) handle setting up mod loaders (such as BepInEx) and managing mods automatically. 
:::

### Step 2: Prepare Modded Game Folder
* Find your game install directory, and copy its contents to a new folder, this will be used to distinguish between your modded and un-modded game installations.

### Step 2.1: DLL override (Linux only)

:::note
This step is only relevant if you're using a GNU/Linux-based operating system.
:::

You should already be running your game under a compatibility layer like Wine, Proton, Proton-GE, or similar. **If you're using Proton 11 or newer, you can skip ahead to step 3.**

To ensure BepInEx gets loaded, you need to set up a DLL override:

<Tabs>
  <TabItem label="Steam">
    Right-click Among Us in your library → `Properties` →
    `General` → `Launch Options`. In the input field, paste
    `WINEDLLOVERRIDES="winhttp.dll=n,b" %command%`. ![Steam DLL
    Override
    steps](@assets/environment-setup/overrides/steam.png)
  </TabItem>
  <TabItem label="Heroic Games Launcher">
    Right-click Among Us in your library → `Settings` →
    `Advanced` → `Environment Variables`. Under `Add New
    Variable`, paste `WINEDLLOVERRIDES` in the `NAME` box and
    `winhttp=n,b` in the `VALUE` box. ![Heroic DLL Override
    steps](@assets/environment-setup/overrides/heroic.png)
  </TabItem>
  <TabItem label="Lutris">
    Right-click Among Us in your library → `Configure` → `Runner
    options`. Under `DLL overrides`, click `Add` and paste
    `winhttp` in the `Key` field and `n,b` in the `Value` field.
    ![Lutris DLL Override
    steps](@assets/environment-setup/overrides/lutris.png)
  </TabItem>
  <TabItem label="Manually using protontricks">
    Run `protontricks --gui` in a terminal → select Among Us →
    `Select the default wineprefix` → `Run winecfg`. In the
    `Libraries` tab, select `winhttp` in the `New override for
    library` dropdown → click `Add` → `Apply`. ![Protontricks DLL
    Override
    steps](@assets/environment-setup/overrides/protontricks.png)
  </TabItem>
</Tabs>


### Step 3: Extracting BepInEx
* Unzip the BepInEx zip file into your new folder. 

### Step 4: First Launch
* Launch the game by opening the executable (Among Us.exe), it may take some time on first launch as it downloads the required files.

### Step 5: Verify Plugin Folder
* After the first launch, a new directory will be created at `BepInEx\plugins`. This is where your mods will need to be placed.

### Step 6: Install Mods!
* Download mods online, most commonly distributed via GitHub. Mods are shared as `DLL` files, so make sure to put your DLLs inside the `BepInEx\plugins` folder.
