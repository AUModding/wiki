:::note
This page covers setting up BepInEx for users to run mods. For making mods, see Setting up your developer environment for modding Among Us.
:::

Among Us is a **Unity IL2CPP Game**. As so, BepInEx is used as a mod loader for the game.

:::tip
Mod managers like [Starlight PC](https://github.com/All-Of-Us-Mods/Starlight-PC) and [Bean Mod Manager](https://github.com/rewalo/BeanModManager) handle setting up BepInEx automatically.
:::

# Manual Installation Steps

### Step 1: Download BepInEx

Download the correct BepInEx zip archive matching your game platform:

| Game Platform | Download Link |
| :--- | :--- |
| **Steam** | [`BepInEx-Unity.IL2CPP-win-x64-6.0.0-be.789+6cea286.zip`](https://builds.bepinex.dev/projects/bepinex_be/789/BepInEx-Unity.IL2CPP-win-x64-6.0.0-be.789%2B6cea286.zip) |
| **Microsoft Store** | [`BepInEx-Unity.IL2CPP-win-x64-6.0.0-be.789+6cea286.zip`](https://builds.bepinex.dev/projects/bepinex_be/789/BepInEx-Unity.IL2CPP-win-x64-6.0.0-be.789%2B6cea286.zip) |
| **Epic Games** | [`BepInEx-Unity.IL2CPP-win-x64-6.0.0-be.789+6cea286.zip`](https://builds.bepinex.dev/projects/bepinex_be/789/BepInEx-Unity.IL2CPP-win-x64-6.0.0-be.789%2B6cea286.zip) |
| **Itch.io** | [`BepInEx-Unity.IL2CPP-win-x86-6.0.0-be.789+6cea286.zip`](https://builds.bepinex.dev/projects/bepinex_be/789/BepInEx-Unity.IL2CPP-win-x86-6.0.0-be.789%2B6cea286.zip) |

:::note
The exact BepInEx version usually doesn't matter (any version newer than 6.0.0-be.735 should work fine), it's just the architecture (x86 vs x64) that's important.
:::

### Step 2: Extracting BepInEx

Unzip the BepInEx zip file into your game install directory. You can find it like this:

- **Steam:** Right-click Among Us in your library → `Manage` → `Browse local files`
- **Epic Games:** Right-click Among Us in your library → `Manage` → click the small folder icon next to `Installation`
- **Itch.io:** Open the Itch.io app → Right-click Among Us in your library → `Manage` → `Open folder in Explorer`
- **Xbox App / Microsoft Store:** Open the Xbox app → Right-click Among Us in your library → `Manage` → `Files` → `Browse...`

### Step 2.1: DLL override (Linux only)

This step is only relevant if you're using a GNU/Linux-based operating system.

You should already be running your game under a compatibility layer like Wine, Proton, Proton-GE, or similar. If you're using Proton 11 or newer, you can skip ahead to step 3.

To ensure BepInEx gets loaded, you need to set up a DLL override:

- **Steam:** Right-click Among Us in your library → `Properties` → `General` → `Launch Options`. In the input field, paste `WINEDLLOVERRIDES="winhttp.dll=n,b" %command%`.
- **Heroic Games Launcher:** Right-click Among Us in your library → `Settings` → `Advanced` → `Environment Variables`. Under `Add New Variable`, paste `WINEDLLOVERRIDES` in the `NAME` box and `winhttp=n,b` in the `VALUE` box.
- **Lutris:**
- **Manually using protontricks:** Run `protontricks --gui` in a terminal → select Among Us → `Select the default wineprefix` → `Run winecfg`. In the `Libraries` tab, select `winhttp` in the `New override for library` dropdown → click `Add` → `Apply`.

### Step 3: First Launch

Launch the game from your library (do not not double-click Among Us.exe!). It may take some time on first launch as it downloads the required files.

### Step 4: Verify Plugin Folder

After the first launch, a new directory will be created at `BepInEx\plugins`. This is where your mods will need to be placed.

### Step 5: Install Mods!

Download mods online, most commonly distributed via GitHub. Mods are shared as `DLL` files, so make sure to put your DLLs inside the `BepInEx\plugins` folder.
