title: A Computer Is Dumb
description: A Good PC Is One That Doesn't Complain
author: "AlchlcDvl"
---

No matter how brilliant a mod's concept is, it will only ever be as good as the
code it's built on. A computer is simultaneously incredibly smart and incredibly
dumb. It's smart enough to calculate complex shortcuts in a millisecond, but
dumb enough to follow your instructions to the letter, even when those
instructions are terrible.

In this subsection, we will explore various optimisations you can make to your
code in the form of:
* Readability
* Performance
* Organisation
