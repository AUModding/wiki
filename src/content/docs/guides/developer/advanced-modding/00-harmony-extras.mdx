After you have used Harmony to patch a some methods, you might run into a situation where you need to hook the game's code in a different way.
Harmony provides multiple patch types, the applications and limitations of which will be discussed here.

This guide assumes you have prior experience with Harmony, or have at least read the
introductory [guide to Harmony patches](../../first-mod/03-harmony-patches) before continuing. 

## HarmonyPatch Overloads

The `[HarmonyPatch]` attribute has multiple alternative overloads that can be very useful for patching different method types.
