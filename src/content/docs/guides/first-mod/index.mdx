## Installing the .NET SDK

Hopefully you don't struggle with this part, otherwise you're gonna have a bad time.

Installing .NET should be easy, just go to the [download page](https://dotnet.microsoft.com/en-us/download)
and grab the latest version of the SDK for your platform. Even though Among Us mods are developed for .NET 6.0,
modern SDK versions can still compile programs made for older versions.

If you are trying to develop mods on a mobile device... please don't.
If you really really want to... I'll let you figure it out. If you can
do that, you are probably smart enough to start modding.

## Important things to know

So there is a lot of terminology and stuff you will be expected to know. Try your best to not forgot.

- IL: Stands for Intermediate Language. It is similar to assembly language, but for the .NET runtime
instead of your computer. C# programs are compiled into IL, then .NET compiles that IL into assembly
at runtime. This is called Just-In-Time, or JIT compilation.

- IL2CPP: The scripting backend used by Among Us. Unity games are typically programmed in C#, but IL2CPP 
converts the IL code into C++, which can be compiled Ahead-Of-Time, or AOT compilation. AOT compilation
means the game typically runs faster. However it makes modding and reverse engineering a pain in the butt.

- BepInEx: The mod loader typically used for Among Us mods. We specifically use the "bleeding edge" builds,
which are "experimental" versions that support stuff like IL2CPP. The specific version you use is VERY IMPORTANT!
Also sometimes

- The Assembly-CSharp / Mono DLL: An essential tool in every modders toolkit!
Thankfully, InnerSloth is merciful enough to provide modders with the `Assembly-CSharp.dll`
file from the Mono build of Among Us. This is the code before the IL2CPP process. The Mono DLL makes it easy for
modders to find out how the game works internally without using a disassembler like IDA or Ghidra.

- [dnSpy](https://github.com/dnSpyEx/dnSpy) / [ILSpy](https://github.com/icsharpcode/ILSpy): A decompiler for .NET programs.
Use it to open the Mono DLL. You can also explore other mods and plugins in these programs. Very useful!
