description: Outlines project setup and the various templates available.

Fortunately for us, someone made a [.NET template for Among Us mods](https://github.com/DaemonBeast/Reactor.Template). 
This template sets up a new BepInEx plugin with a dependency on Reactor.
After installing the .NET SDK, you can open your terminal and enter the following commands to install and use it:
```bash
dotnet new install Daemon.Reactor.Template # install the latest template from nuget.org
dotnet new daemon.reactor -n {Name}        # create a new Reactor plugin
```
