Fortunately for us, there are [.NET templates for Among Us mods](https://github.com/AUModding/AUModding.Templates).
Each template is designed for a different setup.

After installing the .NET SDK, you can open your terminal and use the following command
to install the templates:
```bash
dotnet new install AUModding.Templates
```

There are three templates, Minimal, Reactor, and MiraAPI. For this guide, we will use
the Reactor template. It is usually recommended to build your mods with Reactor,
as it provides many utilities to make mod development easier.

### Minimal

A minimal template which does not include any APIs outside of BepInEx.
```bash
dotnet new aumodding.minimal -n (name)
```

### Reactor

A template which has Reactor preinstalled and some minimal things configured for you.
```bash
dotnet new aumodding.reactor -n (name)
```
Credits: [Daemon](https://github.com/DaemonBeast/Reactor.Template)

### MiraAPI

A template which has MiraAPI preinstalled and some minimal things configured for you.
```bash
dotnet new aumodding.reactor -n (name)
```
Credits: [All Of Us](https://github.com/All-Of-Us-Mods/MiraAPI/tree/master/MiraAPI.Example)
